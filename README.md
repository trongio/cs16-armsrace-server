# CS 1.6 Arms Race server

Counter-Strike 1.6 dedicated server in Docker for playing with friends and bots, with a web dashboard.

## Install (Ubuntu 24.04)

```bash
git clone https://github.com/trongio/cs16-armsrace-server.git && cd cs16-armsrace-server && ADMINS=YOUR_STEAMID64 ./install.sh
```

`ADMINS` is optional: one or more SteamID64s, comma separated (find yours at steamid.io). The installer sets up Docker, generates passwords in `.env`, builds the images, opens the firewall and adds "CS 1.6 Server" and "CS 1.6 Dashboard" shortcuts. Friends need to own CS 1.6 on Steam.

For players outside your network, forward `27015` (TCP+UDP) and `27080` (TCP, map downloads) on your router.

## What's inside

- ReHLDS + ReGameDLL + Metamod-r + AMX Mod X 1.10 + ReAPI
- Modes: **Arms Race** (GunGame), **Deathmatch** (FFA, instant respawn), **Casual**, **Competitive (short)**, **Retakes**, **Rush**
- **Retakes**: the bomb is already planted on a random site; Ts hold it, CTs retake. **Rush**: Ts start at the entrances of a random site and rush it (the other site is closed), CTs defend; a bot carrying the bomb plants once it reaches the site. Both give everyone a free rifle loadout with utility every round. Site spawns in `configs/sites/` are generated by `tools/sites.py` from each map's bomb targets and YaPB graph (de_prodigy has no A/B painted in the map, so its letters are our pick)
- **Bot takeover** in round modes: dead and spectating a bot teammate? Press E (or `!takeover`) to continue as that bot with its health, weapons and ammo
- Weapon finishes (`!skins` `!knife`): 6 finishes for 12 weapons, recolored by `tools/skins.py` from the HLDS view models at install time. They replace your own view model only, and a new player gets the next finish automatically
- Humans wear player models the bots never use, so you can tell friends from bots
- YaPB bots fill empty slots (default 6 players, hard)
- Mode + map vote near the end of every match: type the number in chat. `!vote` starts one any time
- Fun toggles: `!lowgrav` `!headshot` `!speed` `!adaptive` `!announcer` `!colors`, bot takeover (`!takeover toggle` / dashboard)
- Host commands (admins): `!bots <n>` `!diff <0-3>` `!map <name>` `!mode <ar|dm|casual|comp|retakes|rush> [map]` `!restart`
- Dashboard on http://localhost:8016: live scoreboard, map/mode switching, bots, toggles, armory, all-time stats, invite link, QR code for phones
- Server room on the dashboard: health (versions, plugin status), start/stop/restart/repair buttons, live console with a chat feed and an RCON box, and match demos
- HLTV records every map automatically (newest 40 kept in `runtime/demos`, downloadable from the dashboard; copy to `cstrike/` and play with `viewdemo <name>`)
- Self-repair: `tools/doctor.sh check|auto|repair` checks that Metamod, the AMXX modules and the plugins run; `repair` restarts, then rebuilds the image. It runs after every start and from the dashboard (systemd user unit `cs16-doctor.path`)
- FastDL (nginx on :27080) so custom maps download fast

## Files

| Path | What |
| --- | --- |
| `cfg/server.cfg` | hostname, passwords (synced from `.env` by the installer) |
| `cfg/servertools.ini` | modes and their maps |
| `cfg/st/*.cfg` | per-mode settings |
| `overlay/` | everything baked into the server image (plugins, maps, configs) |
| `overlay/addons/amxmodx/scripting/servertools.sma` | the vote/stats/dashboard plugin |
| `overlay/addons/amxmodx/scripting/st_*.inl` | Retakes/Rush, bot takeover, finishes + human models (included by servertools.sma) |
| `panel/` | dashboard (FastAPI + one HTML page) |
| `tools/doctor.sh` `tools/hltv.sh` | health check / repair, demo recorder |
| `tools/sites.py` `tools/skins.py` | generate site spawns / weapon finishes |
| `tools/rcon.py` | `tools/rcon.py <command>` sends an RCON command |

After editing anything in `overlay/`: `docker compose up -d --build`. Start/stop: `./launch.sh` / `./launch.sh stop`, or `./dashboard.sh` to open only the dashboard and start/stop from there.

## Notes

- The dashboard has no login: anyone on your LAN who can open it can run server commands from the RCON box.
- The finishes add about 21 MB to a player's first download (FastDL). To turn them off, empty `runtime/models` and restart.
- After editing `servertools.sma` or `st_*.inl`: `cd overlay/addons/amxmodx/scripting && ./amxxpc servertools.sma -o../plugins/servertools.amxx`, then rebuild.
- Not ported from the CS2 server because CS 1.6 has no equivalent: Workshop maps, glove models, and repair after game updates.
